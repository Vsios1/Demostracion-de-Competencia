SimuladorRAM - Dark+ Edition (VS Code)
========================================

Contenido del paquete:
- src/SimuladorPrincipal.java
- src/PanelEstadisticasConGraficas.java
- src/EstiloDarkConsole.java
- src/SoundManager.java
- lib/ (coloca aquí los jars de JFreeChart: jfreechart-1.5.4.jar, jcommon-1.0.24.jar)
- .vscode/settings.json
- assets/logo.txt (placeholder)

Instrucciones:
1. Abre la carpeta SimuladorRAM_DarkPlus en VS Code.
2. Copia los jars de JFreeChart a la carpeta 'lib' (jfreechart-1.5.4.jar y jcommon-1.0.24.jar).
   Puedes descargar desde https://www.jfree.org/jfreechart/ o Maven Central.
3. Asegúrate de tener JDK 11+ y las extensiones Java en VS Code.
4. Abre src/SimuladorPrincipal.java y ejecuta (Run Java) o presiona F5.

El proyecto incluye un modo oscuro moderno, sonido opcional y gráficos dinámicos.
